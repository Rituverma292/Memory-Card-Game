# 🍎 Memory Card Game 🎮

A fun and interactive **Fruit Matching Memory Card Game** built using HTML, CSS, and JavaScript. Flip the cards, find matching fruit pairs, and test your memory while enjoying this colorful game!

## 🌐 Live Demo
[Play Memory Card Game](https://rituverma292.github.io/Memory-Card-Game/)

## ✨ Features
- 🍓 Colorful fruit cards
- 🃏 Interactive card-flipping gameplay
- 🧠 Improves memory and concentration
- 🎯 Match identical fruit pairs
- 📱 Simple and user-friendly interface
- ⚡ Built with JavaScript for interactive gameplay

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🎮 How to Play
1. Open the game using the Live Demo link.
2. Click on a card to reveal the fruit.
3. Click on another card to find its matching pair.
4. Remember the fruit positions.
5. Match all the pairs to complete the game!

## 📂 Project Structure
- `index.html` – Game structure
- `style.css` – Game styling and layout
- `script.js` – Game logic and card matching
